# PeatPlus

PeatPlus — веб-приложение для продажи торфа и сопутствующей продукции с микросервисной архитектурой на Go.

Проект включает каталог товаров, оформление заказов и систему уведомлений.

## Стек технологий

**Backend:**

- Go

- REST API

- gRPC / Protocol Buffers

- PostgreSQL

- Redis

- Apache Kafka

**Frontend:**

- React

- JavaScript

**Инфраструктура:**

- Docker

- Docker Compose

## Архитектура

Backend построен на микросервисной архитектуре и включает четыре основных сервиса:

- **API Gateway** — единая точка входа для клиентских запросов, маршрутизация и Rate Limiting через Redis.

- **Catalog Service** — управление каталогом товаров и получение информации о продукции.

- **Order Service** — оформление заказов, валидация данных и сохранение заказов в PostgreSQL.

- **Notification Service** — асинхронная обработка событий из Kafka и отправка email-уведомлений.


## Основные возможности

- Просмотр каталога товаров

- Получение информации о товарах

- Оформление заказов

- Сохранение заказов в базе данных

- Отправка email-уведомлений

- Ограничение частоты запросов
